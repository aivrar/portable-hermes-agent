Portable Hermes Agent - Start Here
==================================

For Windows users:

1. Extract the release zip to a normal folder, for example:
   C:\Users\YourName\Portable-Hermes-Agent

2. Double-click START.bat.

   On first launch, START.bat runs the portable setup automatically.
   It downloads embedded Python and dependencies into this folder only.
   No admin rights are required.

3. After setup finishes, Hermes opens the desktop GUI.

Useful launchers:

- START.bat       - easiest first-time launch
- UPDATE.bat      - safest one-click update
- hermes_gui.bat  - desktop GUI
- hermes.bat      - command-line interface
- install.bat     - full setup or repair install

PowerShell setup:

  .\scripts\install.ps1

Safe update:

  UPDATE.bat

  or:

  .\hermes.bat update --backup --yes

Portable Hermes has two separate update paths:

1. Portable distribution update (recommended for normal maintenance)

   - Close Hermes and any running gateways.
   - Run UPDATE.bat.
   - This updates from aivrar/portable-hermes-agent.
   - Runtime folders and custom tools under .hermes are preserved.

2. Optional upstream Hermes Agent update (for the newest core features)

   - Start Hermes after the Portable update.
   - Ask: "Check whether upstream Hermes Agent has updates. Do not install
     anything yet."
   - If you want the update, ask: "Update upstream Hermes Agent while
     preserving Portable Hermes. When finished, tell me whether I should
     restart."
   - Restart Hermes after a successful upstream update.

These are independent. A Portable update installs the Hermes version tested
with this distribution. The optional agent updater pulls newer core code from
NousResearch/hermes-agent while restoring the Portable Hermes integrations.

Most users do not need daily updates. Use UPDATE.bat for new Portable releases,
fixes, or security notices (or every week or two). Check upstream weekly if
you want newer Hermes features; checking daily is optional.

Full updater guide:

  https://github.com/aivrar/portable-hermes-agent/wiki/Keeping-Portable-Hermes-Updated

Documentation:

- README.md has the short overview and quick start.
- docs\Portable-Hermes-Agent-Manual.html is the full manual.
- The PDF manual is also attached to the GitHub release.

Notes:

- Keep the extracted folder together. Runtime files such as python_embedded,
  extensions, node_modules, .env, and cli-config.yaml are intentionally local.
- API keys belong in the setup wizard or .env file, not in Git.
- Extension servers for TTS, Music, and ComfyUI install on first use.
